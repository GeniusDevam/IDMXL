# Validation records

These files record specific development builds and test runs. They are historical evidence, not a claim that every platform or workflow has been qualified. The current scope and remaining checks are in [TEST-EVIDENCE.md](../TEST-EVIDENCE.md) and [RELEASE-CHECKLIST.md](../RELEASE-CHECKLIST.md).

Machine-specific user-profile prefixes are normalized to `%USERPROFILE%` in published records. Byte counts, hashes, request counts and result states are unchanged. Build-specific hashes identify the binaries that were tested; documentation updates do not imply that those binaries were rebuilt. Historical CI links identify the original validation runs and remain the source for their recorded results.
